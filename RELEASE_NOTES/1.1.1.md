# XGlass 1.1.1

This release refreshes the complete XGlass experience while preserving your
existing X.com session and XGlass appearance preferences.

- Redesigned the native Liquid Glass shell with responsive navigation, improved browser controls, feed-width options, and a consistent compact layout.
- Added a full XGlass Settings interface with searchable theme previews, appearance controls, reduced-motion support, and toolbar preferences.
- Reduced unnecessary CPU work through bounded DOM scheduling, deduplicated WebKit updates, hidden-page cleanup, and a modular presentation pipeline.
- Improved route reliability with retries, interface health checks, keyboard navigation, and more dependable profile and direct-message loading.
- Improved feed, composer, reply, and direct-message readability while continuing to suppress promoted posts.
- Added native Finder save panels for images with unique collision-resistant filenames.
- Made the first window open at the preferred desktop size and position without interfering with later resizing or movement.
- Expanded automated coverage and hardened release bundle verification.

XGlass requires macOS 14 or later on an Apple Silicon Mac. Sign-in and
two-factor authentication continue to be handled directly by X.com inside the
embedded WebKit session.
