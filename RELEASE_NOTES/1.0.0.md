# XGlass 1.0.0

First public release of XGlass for Apple Silicon Macs.

- Native SwiftUI macOS shell with a liquid-glass inspired layout.
- X.com session-based browsing through the system WebKit data store.
- Custom sidebar, navigation controls, profile and account-settings routes, direct messages, and compose access.
- Feed presentation refinements for the X web experience, including promoted-content suppression and blended top surfaces.
- Sparkle 2.9.5 updates from signed GitHub release assets.

Sign in to X.com inside XGlass when prompted. Existing X.com two-factor
authentication remains handled by X.com in the embedded sign-in flow.
