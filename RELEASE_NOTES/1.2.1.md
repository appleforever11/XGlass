# XGlass 1.2.1

XGlass 1.2.1 is a release-pipeline compatibility patch.

- SwiftPM test and release builds now compile Swift primary files independently. This avoids a Swift 6.3.3 batch IRGen compiler crash on the supported GitHub macOS runner while leaving the app behavior unchanged.
- The `1.2.0` stability, loading-recovery, notification, theme, image-save, and deterministic-window improvements remain included.
