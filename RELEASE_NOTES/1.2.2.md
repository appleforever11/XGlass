# XGlass 1.2.2

XGlass 1.2.2 is a compiler compatibility patch for the 1.2 stability refresh.

- Replaced SwiftUI appearance-setting method references with explicit setter closures so the supported Swift 6.3.3 toolchain does not crash while emitting the settings view.
- Kept independent primary-file compilation in the SwiftPM test and release scripts to avoid the runner's batched IRGen failure.
- Includes all XGlass 1.2.0 loading, recovery, notification, theme, image-save, diagnostics, and deterministic-window improvements.
