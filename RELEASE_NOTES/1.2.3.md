# XGlass 1.2.3

XGlass 1.2.3 is a release-build compatibility patch for the 1.2 stability refresh.

- Replaced the remaining SwiftUI settings binding method references with explicit setter closures across settings, commands, and the browser toolbar so the supported Swift 6.3.3 toolchain avoids its IRGen reabstraction crash.
- Kept independent primary-file compilation in the SwiftPM test and release scripts to avoid the runner's batched IRGen failure.
- Includes all XGlass 1.2.0 loading, recovery, notification, theme, image-save, diagnostics, and deterministic-window improvements.
