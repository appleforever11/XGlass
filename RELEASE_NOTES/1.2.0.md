# XGlass 1.2.0

XGlass 1.2.0 is a stability and workspace refresh for the native macOS X client.

- Startup now uses a deterministic compact 600 × 1,059 point window and ignores previously restored full-screen or maximized state. The normal traffic lights, manual resizing, and user-entered full screen remain available after launch.
- Loading recovery now waits for rendered destination content, uses bounded probes and retries, protects drafts and attachments, and offers explicit browser, standard-appearance, origin-reload, and web-session restart paths without clearing sign-in data.
- Diagnostics report bounded, content-free load timing and resource-error summaries. Deferred styling, scroll restoration, media readiness, and WebKit failure handling are capped so stalled pages do not cause runaway work or destructive reloads.
- The notification bell mirrors live unread updates and clears when X reports them read. New-post prompts receive a visible highlight until opened.
- Added Golden Gate, Big Sur, Mojave Dusk, Sonoma Hills, Tahoe Tide, Violet Bloom, and additional macOS-inspired themes, plus accent customization, responsive feed sizing, focus mode, and the Command-K quick switcher.
- Native image saves remember the last destination folder, validate downloaded image data, avoid clobbering invalid responses, and provide persistent progress feedback. Find in Page, traffic-light positioning, logo placement, and signed bundle checks were also tightened.

XGlass continues to use X.com's normal WebKit session. No private API credentials are required, and existing cookies, preferences, and account state remain in place.
