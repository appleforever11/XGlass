# XGlass 1.2.4

XGlass 1.2.4 is a release-gate reliability patch for the 1.2 stability refresh.

- Run the WebKit fixture suite serially in the SwiftPM release check so parallel XCTest workers cannot terminate isolated `WKWebView` fixtures under runner resource contention.
- Keep independent primary-file compilation and the explicit SwiftUI binding closures required by the supported Swift 6.3.3 toolchain.
- Includes all XGlass 1.2.0 loading, recovery, notification, theme, image-save, diagnostics, and deterministic-window improvements.
